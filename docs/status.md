## 2. งานที่เสร็จแล้ว

ทุก feature ทำตามขั้นตอนเดียวกัน: สัญญา API (OpenAPI) → migration → store (sqlc) → service → handler → หน้าจอ admin ไทย/อังกฤษ → test → เอกสาร · ทุก repository มี test แยกข้อมูลสอง tenant (RLS) และทุก endpoint มี contract test ผ่าน validator จริง

### งานสนับสนุนที่ทำเพิ่ม

- **รันบนเครื่องตัวเองได้โดยไม่ต้องมี Keycloak** — `make dev-env` → `make migrate` → `make dev-seed` → `make run-api` / `run-worker` / `run-web` แล้วกด "เข้าสู่ระบบ" (dev login ใช้ได้เฉพาะ `next dev`, ปิดเสมอใน production) · ดู README หัวข้อ "รันบนเครื่องตัวเอง"
- **โครงระบบ (PLT-01), multi-tenant (PLT-02), หลายภาษา (PLT-03)** ทำไปมากแล้ว (middleware 13 ขั้น, RLS + test แยก tenant, ข้อความไทย/อังกฤษ, ปี พ.ศ.) แต่ยังไม่ได้ปิดสถานะใน backlog เพราะเหลือส่วนที่ต้องรอ feature อื่น (ตัวระบุ tenant ของ public API, provisioning tenant, CI)
- **Bug ที่เจอและแก้ระหว่างทดสอบ**: validator ของ API ไม่เคยตรวจอะไรเลย · path ยาวเกิน ~76 ตัวอักษรได้ 500 เพราะ audit action ล้น · BFF ส่ง `Accept-Language` ดิบทำให้ทุก request จาก browser ได้ 400 · builder แบบฟอร์มทิ้งงานที่ยังไม่บันทึกเมื่อโหลดข้อมูลใหม่ · BFF ไม่ส่ง IP / browser ของผู้ใช้ต่อให้ API (audit เห็นแต่ IP ของ BFF) · style ของ component ใน package ร่วมไม่ถูกสร้าง · test แจ้งเตือนพังช่วงกลางคืน
- **การทดสอบ**: Go test ทั้งหมดผ่าน (รันกับ Postgres, Redis, S3, ClamAV, OpenBao จริง) · Vitest ของ package หน้าเว็บ · E2E ด้วย Chromium บนระบบจริงของทุก feature ที่มีหน้าจอ
