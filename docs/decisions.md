# Decisions log

เอกสารนี้มีสองส่วน: (1) สิ่งที่ **ตัดสินแล้ว** ตอนรวมชุด SA กับ Development Plan เข้าเป็นชุดความรู้นี้ และ (2) คำถามที่ **ยังเปิดอยู่** ซึ่งต้องให้ลูกค้า / ฝ่ายกฎหมาย / สถาปนิกตอบ
